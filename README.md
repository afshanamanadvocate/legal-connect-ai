
# AI-powered Legal Connect

AI-powered Legal Connect is a learning project to connect clients with lawyers using AI.

### 🎯 Goal
To make legal help easy and accessible for everyone in Pakistan.

### ✨ Features to Build
- User can ask legal questions in Urdu / English
- AI will suggest relevant lawyer / legal info
- Client-Lawyer chat system
- Case categories (Family, Criminal, Property etc.)

### 🛠️ Tech Stack (Learning)
- Frontend: HTML, CSS, JavaScript
- Backend: Python
- AI: ChatGPT API / Open Source LLM
